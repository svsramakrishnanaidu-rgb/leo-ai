# Contributing to LEO.AI

Thank you for helping improve this independent civic-assistance prototype.

## Getting started

1. Fork the repository and create a descriptive branch.
2. Install dependencies with `npm ci`.
3. Start the app with `npm run dev`.
4. Keep changes focused and document user-visible behavior.
5. Run `npm run lint` and `npm run build` before opening a pull request.

## Contribution ideas

- Make forms easier to use with keyboards and screen readers.
- Improve Telugu and Hindi translations.
- Add automated tests for issue classification and local storage.
- Improve map usability and third-party service error handling.
- Help move AI requests to a secure server-side integration.
- Add verified screenshots and reproducible bug reports.

## Pull request checklist

- [ ] Change has a clear motivation and description.
- [ ] User data and keys are not added to the repository.
- [ ] No feature claims official government integration without verification.
- [ ] Lint and build commands complete locally.
- [ ] UI changes consider small screens and keyboard navigation.
- [ ] Documentation is updated when behavior changes.

## Responsible disclosure

For suspected security issues, follow [SECURITY.md](./SECURITY.md) rather than opening a public issue containing an exploit or secret.

## Community expectations

Be respectful and constructive. Critique code and ideas, not people. Don't share personally identifiable complaint data in issues or pull requests.
